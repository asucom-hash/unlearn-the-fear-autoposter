# Unlearn The Fear — Automatic Quote Posts

This repository is being set up for a **free**, Python-based quote artwork generator and a GitHub Actions workflow that can post to the Unlearn The Fear Instagram and Facebook Page using Meta's Graph API.

**Safety:** Automatic publishing starts OFF. Do not enable it until the image preview, GitHub Pages hosting, account IDs and Meta token permissions are verified. Never commit access tokens or passwords to this public repository.

The fully packaged starter project is available in the original ChatGPT conversation. The repository's files are being installed from that starter project.
